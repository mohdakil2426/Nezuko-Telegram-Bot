# i18n API Reference

**Package:** `@grammyjs/i18n`

Internationalization and localization support.

## `I18n`

Main class for managing translations.

```ts
import { I18n } from "@grammyjs/i18n";

const i18n = new I18n({
  defaultLocale: "en",
  directory: "locales",
  useSession: true,
});

bot.use(i18n);
```

### Options

- `defaultLocale` - Fallback language
- `directory` - Path to translation files
- `useSession` - Store user locale in session
- `sessionName` - Custom session key name
- `fluentContextOptions` - Fluent formatting options
- `localeNegotiator` - Custom locale detection

## Translation Files

### File Structure

```
locales/
├── en/
│   └── bot.ftl
└── de/
    └── bot.ftl
```

### FTL Format (Fluent)

```ftl
# Simple message
welcome = Welcome to the bot!

# With variable
hello = Hello, { $name }!

# With selector
messages-count =
    { $count ->
        [0] No messages
        [one] One message
       *[other] { $count } messages
    }

# Command description
start-command = Start the bot
```

## Context Methods

### `ctx.t(key, variables?)`

Get translated string.

```ts
bot.command("start", (ctx) => {
  ctx.reply(ctx.t("welcome"));
});

bot.command("hello", (ctx) => {
  ctx.reply(ctx.t("hello", { name: ctx.from.first_name }));
});
```

### `ctx.i18n.getLocale()`

Get current locale.

```ts
const locale = ctx.i18n.getLocale(); // "en"
```

### `ctx.i18n.setLocale(locale)`

Set locale for user.

```ts
bot.command("lang", (ctx) => {
  ctx.i18n.setLocale("de");
  ctx.reply("Language changed to German!");
});
```

## Locale Detection

```ts
const i18n = new I18n({
  localeNegotiator: (ctx) => {
    // Check user profile
    if (ctx.from?.language_code) {
      return ctx.from.language_code;
    }
    // Default
    return "en";
  },
});
```

## Multiple Namespaces

```ts
const i18n = new I18n({
  directory: {
    bot: "locales/bot",
    errors: "locales/errors",
  },
});

ctx.t("bot:welcome");
ctx.t("errors:not-found");
```
